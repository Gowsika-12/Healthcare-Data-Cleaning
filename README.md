# Healthcare-Data-Cleaning # Healthcare Data Cleaning & Understanding

## Objective
Clean and analyze healthcare data containing patient demographics, diseases, medications, and dosage information.

## Tasks Performed
- Data cleaning
- Missing value handling
- Duplicate removal
- Pivot table analysis
- Disease frequency analysis
- Average age calculation

## Tools Used
- Microsoft Excel
- Pivot Tables
## Key Findings
- Diabetes was the most common disease.
- Average patient age was approximately 48 years.
- Missing values and duplicate records were successfully handled.
